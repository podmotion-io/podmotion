# PodMotion — Documentation Index

## ADRs (`docs/adr/`)

Architectural Decision Records capturing every significant design choice in PodMotion — CRIU integration, CRD data model, TCP preservation, security invariants, and more. Each ADR is immutable once accepted; superseding decisions open a new record.

## Contributing (`CONTRIBUTING.md`)

How to propose changes, the ADR authoring process, and the review expectations for pull requests.

## Proof artifacts (`docs/proof/`)

Machine-readable and human-readable proof run outputs that attest to milestone completion — freeze-window measurements, seq-delta results, and 10-run statistical summaries for each North Star gate.

## Postmortems (`docs/postmortems/`)

Root-cause analyses and correction chains for defects and incidents discovered during sprint execution, following the project's standard postmortem schema.

## Roadmap (`docs/roadmap/`)

Forward-looking capability roadmap organized by milestone tier; tracks open problems (multi-flow CRIU consistency, N-flow seq preservation, multi-container live migration) and their target sprints.

## Security (`docs/security/`)

Security architecture documentation, threat model, and compliance notes covering checkpoint confidentiality, seccomp invariants, and RBAC posture.
